## 二、目标清单与明确边界（Non-Goals）

### 2.1 本阶段落地 4 大能力

1. **0-Token 盘后执行与汇率拆解账单**（纯 Python 确定性计算）：
   - 对比当日早盘快照 vs 盘后收盘快照，精准拆出全组合与双账户的 **本地股价盈亏（£）vs FX 汇率影响（£）**（直接复用 T212 原生 `PositionItem.fx_impact`，当日股数变动标的单独归入 `INTRADAY_TRADE` 绝不伪造未实现盈亏差）；
   - 执行 **Plan vs Actual（计划 vs 实盘纪律审计）**：统计当日成交滑点、计划外成交、Invest 浮盈 `≥ +15%` 漏推保本止损单、以及跌破止损线仍无止损挂单的裸露仓；
   - 硬门控筛选重仓异常波动候选（平静日 0 候选 → 0 搜索、0 额外 Token）。
2. **增强现有 T+5 / T+20 结算反思（补齐 MFE/MAE + 滑点 + 2×2 过程矩阵 + 异常单 Flash Lite 催化检索）**：
   - 修复 `settlement_mixin.py` 现有盲区：把已入库但从未喂给 DeepSeek 的 `mfe_pct`、`mae_pct`、`actual_filled`、`execution_slippage_pct` 与 `regime` 注入反思 Prompt；
   - 引入确定性 **2×2 过程矩阵**（`GOOD_WIN / GOOD_LOSS / BAD_WIN / BAD_LOSS`），强制 DeepSeek 解耦过程与结果（`GOOD_LOSS` 严禁建议放宽止损，`BAD_WIN` 高亮警示运气陷阱）；
   - 仅对**大幅偏离的结算单**（`|raw_return|≥8%` 或 `|alpha|≥6%` 或 `mae≤-8%`）及**硬门控盘后异动重仓**，调用 `gemini-3.5-flash-lite` + Google Search 抓客观公告（无实质公告强制返回“无明确基本面公告，属市场/板块跟随”，严禁编故事）；全晚联网检索共享硬上限（默认 `≤3` 只，单次 30s 硬超时，异常静默降级绝不阻断结算）。
3. **打通下游 3 处现成信息断层**：
   - **周六 AI 诊断补全**：将已算出但未喂给 DeepSeek 的 `shadow_stats`（护栏避雷 vs 错杀）、`exit_rule_ab`（阶梯止损 vs 旧移动止盈）、`adoption_stats`（采纳率与平均滑点）、`quadrant_counts`（2×2 过程分布）及近 5 日盘后账单汇总拼入 `_generate_weekly_diagnosis`；
   - **`/report` & `/pick` 历史教训补标签**：零迁移复用既有 `regime` 与 `MFE/MAE` 字段，避免把熊市防御教训错误套到牛市领涨股；
   - **0-Token 按需指令 `/review` + 静默推送节制**：工作日盘后默认静默写库，仅触发纪律偏离告警或重大公告异动时推送一条 `<=250` 字短提醒；随时可用 `/review` 0-Token 查看最近盘后账单与近期 2×2 复盘。
4. **顺手修复 `settlement_mixin.py` 既有一处可靠性隐患**：
   - 现有 L460-L463 在 LLM 生成反思失败时 `continue` 跳过整笔写库，导致结算单滞留 `PENDING`；改为仅行情/基准缺失时重试，反思 LLM 临时故障时降级以 `reflection_lesson=""` 完成数值结算（T+20 仍可补写）。

### 2.2 明确不做（Non-Goals & 不可破坏红线）

- **严禁自动修改** `.agents/skills/*`、`prompts.py` 规则、评分权重或风控参数；
- **严禁新增独立晚间定时任务**抢占 `execution_lock`（全部复用 `22:00 UK` `daily_settlement` 槽位）；
- **严禁破坏影子隔离契约**（`SHADOW_REJECTED / SHADOW_SETTLED` 保持 0-Token、不进 `quadrant_counts` / `lessons` / 真实胜率）；
- **严禁违反 `AGENTS.md` 六条铁律**：SQLite 单写锁 `_connect(write=True)`、降级数据禁回写、双币种与 `GBp/GBP` 100 倍校验、Telegram 禁 `#`/`**`、英搜中出、零删库幂等迁移；
- **安全红线**：不新增任何 `http(s)://` 出网域名（仅复用既有 `gemini-3.5-flash-lite` 与 `deepseek-flash`）、不新增凭据环境变量、不改动风控护栏模式开关。

### Step 2：纯确定性盘后账单与 2×2 过程分类模块（0-Token）

- **新增文件**：`src/data_providers/analytics/postmarket_review.py`（同步导出至 `src/data_providers/analytics/__init__.py`）
  1. `classify_process_quadrant(*, action, raw_return_pct, alpha_pct, fill_status, actual_filled, execution_slippage_pct) -> str`：
     - **过程判定**：`actual_filled == 1` 且 `execution_slippage_pct is not None and execution_slippage_pct > 1.5` → `BAD`（大额追高/劣化滑点）；否则 `GOOD`（`actual_filled is None` 理论信号默认 `GOOD` 并在展示层标注「理论信号」）；
     - **结果判定**：方向感知 `raw_return_pct >= 0` → `WIN`，否则 `LOSS`；
     - 缺 `raw_return_pct` 返回 `""`（不强行分类）。
  2. `build_eod_attribution_ledger(morning_snap, eod_snap, *, regime="", today_recs=None, histories=None, strategy=None, uk_date="") -> dict[str, Any]`：
     - **股价 vs FX 汇率拆解**：
       - 对 ISA 与 Invest 逐仓按 `(account, yahoo_symbol)` 对齐 `morning_snap` 与 `eod_snap`；
       - 股数未变（`abs(qty_eod - qty_am) <= 1e-6`）：
         - `delta_pnl_gbp = eod.pnl - am.pnl`
         - `delta_fx_gbp = eod.fx_impact - am.fx_impact`
         - `delta_local_gbp = delta_pnl_gbp - delta_fx_gbp`
         - `local_ret_pct = (eod.cur_price / am.cur_price - 1.0) * 100.0`（前提 `am.cur_price > 0` 且两快照 `inst_currency` 一致）
       - 股数变化（当日新开/加减/清仓）：标记 `intraday_traded=True`，从 `eod_snap.recent_orders`（当日 UK 日期）提取成交明细，**绝不混入未实现盈亏差值**；
       - 聚合全组合及分账户的 `local_pnl_gbp`、`fx_pnl_gbp`、`total_mark_pnl_gbp`，按 `delta_local_gbp` 提取 Top 3 贡献赢家与 Top 3 拖累输家。
     - **Plan vs Actual 纪律扫描**：
       - **当日实盘成交核对**：比对 `eod_snap.recent_orders` 当日成交与近 2 个交易日 `pick_recommendations`，标注建议价 vs 实际成交滑点（`> +1.0%` 记为 `HIGH_SLIPPAGE` 告警）与无对应建议的计划外建仓（`UNPLANNED_TRADE`，核心宽基 ETF 买入豁免）；
       - **Invest 漏推保本与裸露止损扫描**：复用 `deployment_gate/ledgers.py` 与 `portfolio_rules/models_and_friction.py` 同一口径（`is_invest_core_beta_symbol` 豁免宽基）：
         - 浮盈 `>= +15%`（`INVEST_LADDER_BREAKEVEN_ADVISORY_PCT`）且未挂全额（`>=0.99×qty`）保本 `SELL STOP/STOP_LIMIT` → 记 `MISSING_BREAKEVEN_STOP` 告警；
         - 浮亏超过自适应止损警戒线且无任何 `SELL STOP` 挂单 → 记 `UNPROTECTED_LOSS` 高优告警。
     - **硬门控异动事件候选（为 Step 3 供靶）**：
       - 过滤掉核心宽基 ETF（`is_invest_core_beta_symbol`），仅当个股满足：
         - `abs(local_ret_pct) >= max(postmarket_anomaly_min_move_pct, 2.0 * atr_pct)`（无 ATR 时按 `4.5%` 兜底）且相对分区基准当日涨跌超额 `>= 2.5%`；
         - 或当日有实盘买入但当日收盘本地回撤 `<= -3.0%`；
       - 按 `abs(local_ret_pct)` 降序返回 `anomaly_candidates`；平静日为空列表。
  3. `format_postmarket_review_text(ledger, *, event_cards=None, max_chars=900) -> str` & `format_postmarket_alert_text(ledger, *, event_cards=None, max_chars=250) -> str`：
     - 纯文本紧凑输出，严禁 `#` 与 `**`；单日告警明确标出触发原因（纪律项或实质公告）。

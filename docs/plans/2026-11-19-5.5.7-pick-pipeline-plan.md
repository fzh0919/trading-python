## 一、 核心痛点总览（2026-11-19 线上全链路实跑审计）

对 `/pick` 的 **量化初筛 → 门控 → Researcher（Hydrogen HIGH）→ Critic（Neon MEDIUM）→ Python 护栏 → Telegram 渲染 → 语义质检** 全链路逐行审计后，锁定了 10 项实质性逻辑/数学/架构缺陷：

1. **上游发票、下游硬杀**：`/report` 已批 `ISF.L`（£1,000）且用户已挂 `100 股 @ 1020 GBp`，但 `/pick` 复用 07:30 静态 `gate_ctx` 未核 `approved_report_core_gbp > 0`，仍向 Researcher 签发 `ISF.L £1,600` 政策票据，导致 Researcher 与 Critic 白写一整条注定被拦截的提案。
2. **拦截后余现沦为假账**：`ISF.L` 被拦截后，`_reconcile_pick_headline` 只改了标题，未更新 `consistency_and_cash_note`，Telegram 底部仍推送 Critic 拦截前口算的错账（`余现£29,698 / ISA £18,322`），且 Critic 口算时重复扣减了已在挂单占用里的 `£1,020`。
3. **汇率未回写逼 LLM 口算双钱包**：`pick_agent.py` 漏调 `refresh_portfolio_fx`，导致精确现金底座报错 `GBP/USD 暂缺`。
4. **Regime 与 R:R 门槛口径撕裂 + 上下股数打架**：
   - `resolve_invest_dynamic_rr_floor` 未纳入 `VIX`（`NEUTRAL` 给 `2.0:1`，早报文字红线自造 `2.5:1`）；
   - Python `_resolve_pick_rr` 与 `compute_risk_based_size_gbp` 未把英股 0.50% 不可退印花税 + 价差计入止损风险分母，导致同一张 `LSEG.L` 在 Telegram 上下分别给出 `16股(£1,530)` 与 `上限£1,800(≈18股)`（真买 18 股止损将实亏 £118 超风险预算 11%）。
5. **门控误报假右侧猎物 & 选股漏斗失真**：
   - `_scan_a_equity_candidates` 漏检 `现价 > MA200` 与 `weekly_bullish`，把周空头 `RR.L / SIE.DE` 报成右侧猎物诱发 6 次无效工具调用；

6. **Critic 信息盲审（伪独立风控）**：`critic_sys` 要求核查 ATR/RSI/财报/除息/相关性/卖方均值，甚至写了空指指令`除息数据见候选行的「除息」标注`，但 `critic_prompt` 根本未给一手事实数据，100% 依赖 Researcher 二手转述。

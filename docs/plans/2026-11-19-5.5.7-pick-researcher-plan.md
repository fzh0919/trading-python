## 背景与实跑诊断摘要

基于 `2026-11-19` 线上 `/pick` Researcher（`gemini-4-hydrogen`, `think=HIGH`）完整输入/工具往返/输出日志的逐行审计，模型本体的推理与守纪能力已达标，但上游确定性管道存在 **6 处逻辑冲突/数据断层** 与 **5 处隐蔽漏斗缺陷**：

1. **上游发票、下游硬杀**：`/report` 已批 `ISF.L`（£1,000）且用户已挂 `100 股 @ 1020 GBp`，但 `/pick` 直接复用了 07:30 静态 `gate_ctx` 且未检查 `approved_report_core_gbp > 0`，仍向 Researcher 签发 `ISF.L` £1,600 政策票据，逼其写完一整条“注定被 `_apply_gate_channel_constraints` 拦截”的提案。
2. **门控触发器误报“假右侧猎物”**：`_scan_a_equity_candidates` 漏检 `现价 > MA200` 与 `weekly_bullish`，把破位周空头的 `RR.L` 与 `SIE.DE` 报成右侧猎物，直接诱发 6 次无效工具调用。
3. **汇率未回写、逼 LLM 口算双钱包**：`pick_agent.py` 拿到 `macro.gbp_usd` 后只调用了 `set_gbp_usd_rate`，漏调 `refresh_portfolio_fx`，导致精确现金底座报错 `GBP/USD 暂缺`，违反“双币种隔离、严禁交给 LLM 口算”系统铁律。
4. **Regime 与 R:R 门槛口径撕裂**：确定性 `resolve_invest_dynamic_rr_floor` 未纳入 `VIX` 高波警戒线（`NEUTRAL` 给 `2.0:1`），而早报文字红线基于 `VIX > 22` 自造了 `弱市 2.5:1`，造成早报、Researcher、下游 Python 护栏三处口径不统一。
5. **通道锁死未短路 + 选股漏斗 R:R 盲区**：
   - ISA 个股通道关闭时，上游仍全量执行 ISA 8 只个股初筛、DeepSeek 过滤、Finnhub 聚合与 Google Search 联网摘要；
   - `scoring.py` 中 `upside_pct` 对 Invest 总分影响仅 ±3 分，且误给 Invest 英股加 `+2.5`“免换汇”奖励（无视 0.50% 不可退印花税）；同时未提前过滤 15 天清仓冷却标的，DeepSeek 初筛行也缺 `upside_pct` / `ATR14%`，导致 Invest Top 8 被 6 只目标空间 `≤ 9%`、数学上不可能达标 R:R 的标的霸榜。
6. **“嘴上禁工具，数据逼工具”+ 上下文高噪**：
   - `summary_line` 缺失 `ATR14`、`目标均价`、`周线状态/周RSI`、`ADX`、`CYQ 均成本`，逼迫 Researcher 对已在榜单里的 5 只票重调 `inspect_ticker`（叠加误报与重搜共发起 2 轮 12 次工具调用）；
   - 存量持仓信号把 7 只已锁死的 ISA 持仓标成绿色 `🟢 [加仓候选]`，与门控直接打架；早报已执行的挂单裁决未按实时挂单做差集过滤；Finnhub `deep_intel` 在 `summary_line` 和 `cand_details_section` 重复出现；Researcher 自由输出 ~2,800 字给 Critic 增加无谓解析负担。

## Wave 1：确定性真源统一（动态 R:R、双钱包 FX、盘中门控同步与假右侧修复）

> **哲学归属**：顶层 CIO 门控 + 管道数据卫生（零污染双轨边界）

### 1. 统一 Python 动态 R:R 门槛（单一真源）
- **改动文件**：`src/config.py`、`src/engine/portfolio_rules/dual_philosophy.py`、`src/engine/portfolio_rules/holding_eval.py`、`src/engine/portfolio_rules/sizing.py`、`src/engine/portfolio_rules/risk_override.py`、`src/engine/deployment_gate/banner.py`、`src/agents/pick_agent.py`
- **实现要点**：
  1. `StrategySection` 新增可配置阈值 `invest_vix_tighten_rr_threshold: float = Field(default=22.0, gt=0.0, le=100.0)`。
  2. `resolve_invest_dynamic_rr_floor(regime, tech, strategy, *, vix: float | None = None)` 升级为统一真源：
     - `regime == "RISK_OFF"` **或** `vix >= invest_vix_tighten_rr_threshold` **或** 个股本身 `WEAK / dist_ma200_pct <= 0` → 返回 `invest_min_rr_weak_or_risk_off`（默认 `2.5`），标签区分 `高波防御门槛(VIX≥22)` / `弱势/防御高赔率门槛`；
     - `regime == "RISK_ON"` 且 `_is_right_side_leader(tech)`（且 `vix < threshold`）→ 返回 `1.6`；
     - 其余 `NEUTRAL` → 返回 `2.0`。
  3. 同步把 `vix`（取自 `macro.vix`）传入 `evaluate_portfolio`、`sizing`、`apply_risk_override_guardrail` 与 `evaluate_deployment_gate`，并将当日确定的 `invest_min_rr_floor` + `invest_rr_tier_label` 写入 `gate_ctx["invest"]`。
  4. `_format_gate_constraint_block` 与早报 FactSheet 统一直接印出该确定性数字（例：`今日 Invest 动态 R:R 底线：≥ 2.5:1（VIX 25.3 ≥ 22 高波防御）`），早报/Researcher/Critic/Python 护栏四处读同一口径，彻底杜绝 LLM 自造门槛数字。

### 2. 修复 `/pick` 实时双钱包汇率回写
- **改动文件**：`src/agents/pick_agent.py`
- **实现要点**：对齐 `morning_report.py:430-440`，在 `pick_agent.py:1072-1076` 优先调用 `portfolio = t212.refresh_portfolio_fx(portfolio, macro.gbp_usd) or portfolio`，再降级 `set_gbp_usd_rate`，彻底消除 `GBP/USD 暂缺` 与 LLM 口算钱包余额。

### 3. 修复门控“假右侧猎物”与盘中实时挂单同步
- **改动文件**：`src/engine/deployment_gate/triggers.py`、`src/agents/pick_agent.py`
- **实现要点**：
  1. `_scan_a_equity_candidates`（`triggers.py:128-153`）补齐右侧结构硬门槛：
     - 必须满足 `tech.dist_ma200_pct is not None and tech.dist_ma200_pct > 0.0`（严禁把跌破 MA200 的票标为右侧猎物）；
     - 必须满足 `tech.weekly_bullish is not False`（剔除周空头）；
     - 明确回踩下限（例如 `dist_ma50_pct >= -2.0%` 且 `<= tol`，防止 `-2.9%` 深度破位 MA50 被误判为健康回踩）。
  2. `_format_gate_constraint_block`（`pick_agent.py:91-106`）新增两道同步检查：
     - 若 `float(isa_g.get("approved_report_core_gbp") or 0.0) > 0.0`，**不再向 Researcher 签发核心宽基政策票据**，改为明确提示：`今日 /report 已批核心宽基定投 £X，/pick 不再重复签发核心宽基票据，专注 Invest 右侧机会或必要换仓`；
     - 同步比对当前实时 `portfolio.isa.pending_orders`：若政策票据标的（如 `ISF.L`）已在实时活动买单中覆盖当日额度，同样标为“已挂单执行中，勿重复建仓”。

## Wave 2：量化初筛与 DeepSeek 漏斗升级（通道短路、冷却过滤与 R:R 可达性）

> **哲学归属**：双轨隔离强化（ISA 价值/质量 vs Invest 趋势/赔率与摩擦精准定价）

### 1. 通道关闭上游短路 + 15 天冷却期前置剔除
- **改动文件**：`src/agents/pick_agent.py`、`src/engine/screener/runner.py`
- **实现要点**：
  1. `run_quant_screener` 新增可选参数 `enable_isa_equities: bool = True`、`enable_invest_track: bool = True`、`excluded_symbols: set[str] | None = None`。
  2. 当 `gate_ctx` 中 `isa.equity_open is False`（且用户未指定 `focus_query`）：
     - 直接跳过 ISA 个股轨道的 Stage 2 富化、DeepSeek 过滤、Finnhub 聚合与 Google Search 联网搜索；
     - 若 `isa.etf_open is True` 且无已批/已挂政策票据，仅按政策票据单独补齐该 ETF 数据，不再扫描 8 只无用 ISA 个股。
  3. 前置计算 `trade_behavior` 中的 15 天清仓冷却名单（如 `PANW/CF/BE/INTC/META/NOW`），在 `trade_cadence_guard_mode == "hard"` 时直接传入 `excluded_symbols`，避免冷却股占满 Top 8 候选名额并浪费搜索配额。

### 2. 修复 Invest 轨的“R:R 盲区”与“英股印花税倒挂”
- **改动文件**：`src/engine/screener/scoring.py`、`src/agents/pick_agent.py`
- **实现要点**：
  1. **修复 Invest 英股摩擦计分倒挂（`scoring.py:475-485`）**：
     - 保留 ISA 长线对 `.L` 英股免换汇的温和加分（`+2.5`）；
     - 对 `INVEST_TACTICAL` 短线轨，买入英股（非 ETF）需缴纳不可退的 `0.50%` 印花税 + 较高价差，**不再给 `+2.5` 奖励**，改为中性偏负（`-1.0`）并标注 `含0.5%印花税(短线高摩擦)`，避免短线榜单被高摩擦英股抬轿。
  2. **Invest 轨加入前瞻 R:R 可达性软门（`scoring.py`）**：
     - 用 `atr_floor_pct = max(1.5 * atr14_pct, 4.0)`（缺失 ATR 时兜底 `4.5%`）与 `upside_pct` 估算理论净 R:R：`est_rr = (upside_pct - est_friction_pct) / (atr_floor_pct + est_friction_pct)`；
     - 对 `INVEST_TACTICAL` 轨：若存在有效分析师覆盖（`analyst_count >= 3`）且 `upside_pct` 明显低于当日门槛所需空间（例如 `est_rr < 0.7 * min_rr_floor`，如 `+3%~+7%` 空间）：
       - 在 `dim3` / 总分施加阶梯惩罚（`-8` 至 `-15` 分），并写入 `cons`（`空间偏窄(预估R:R≈0.8:1)`），**注意**：保留 `RISK_ON` 领涨股（允许看高目标价折价）与无分析师覆盖标的豁免，防止在强牛市误杀超预期突破股。
  3. **修复 Invest 轨 `Dim 1` 截断饱和（`scoring.py:208-314`）**：
     - **反查护栏**：必须严格保持 `dimension_scores["trend_rs"]` 契约区间在 `[0.0, 30.0]`（现有单测断言 `<= 30.0`），且**不改动 `ISA_LONG_TERM` 的 `dim1` 计分逻辑**（保护巴菲特价值轨）。
     - 仅针对 `INVEST_TACTICAL`：把 `dim1` 起步基准与重复趋势底分小幅下调（使普通多头不再 7/8 顶格饱和在 `T100%`），把顶部 `24~30` 分区间留给 **20日/60日相对强度 RS 为正且斜率向上** 的真正右侧领涨股，恢复区分度。
  4. **DeepSeek 初筛行 `_prefilter_row` 补入关键过滤指标（`pick_agent.py:488-503`）**：
     - 增补 `行业/地区`、`目标空间`、`ATR14%`、`60日RS`、`预估R:R`（Invest 轨）与 `安全边际/FCF`（ISA 轨），让 DeepSeek ID Filter 真正按双轨标准淘沙，而不是只看抽象总分。

## Wave 3：Researcher 上下文“高信噪比重构”、1-to-1 深搜与买方契约

> **目标**：让 Researcher 拿到“一次看全、既有结构价格锚点又有 30 天催化+反方雷区”的机构级事实底座，把常规 `/pick` 工具调用从 12 次压到 0~2 次，同时零破坏 Gemini Implicit Cache 静态前缀与下游 Critic 结构化输入契约。

### 1. 补全候选摘要行决策刚需 + 真实结构价格锚点 + 卖方分歧区间
- **改动文件**：`src/engine/screener/scoring.py`
- **实现要点**：
  - `_format_summary_line` 增补本地已算好的 0-Token 决策字段：
    - `[行业/地区]` 标签（如 `[Financials/UK]`、`[Tech/US]`，一眼防红线禁区与隐性因子扎堆）；

    - `target_low_price`、`target_mean_price`、`target_high_price` **必须全部通过与 `_safe_target_upside_pct` 相同的 `.L` 100 倍量级校准函数**（严禁裸拼 Yahoo 原始值）；

  - 删除行内重复废词：
    - 删除每行重复的 `广度 NEUTRAL`（顶部已全局声明）；
    - 修正不严谨的 `美股可用USD钱包免换汇`：仅在 `usd_avail >= min_invest_order_gbp * rate` 时写 `USD钱包可用`，不再误导成绝对免换汇。

## 一、全版本不可破坏红线（所有模块共同契约）

任何模块（M1~M6）施工前、施工中、验收前，必须逐条确认以下防守与工程铁律 **100% 未被削弱**：

1. **危机极速防守不动**：`RISK_OFF`（危机防御态）保持 **1 天极速触发**、Invest 槽位 `= 0` / 热力 `= 0%` 完全冻结新开个股、四步渐进防守不变。
2. **单笔与组合硬风控不动**：Invest 硬止损与 `max(1.5×ATR, 4%)` 噪声地板、严禁亏损摊平、跨账户单票硬上限 `12%`、相关性 `>= 0.85` 去重拦截、财报前 5 天禁开仓、除息前 3 天护栏、连损 2 笔冷静期、周 ≤2 / 月 ≤6 / 单日 ≤1 新开个股配额，全部保持 `hard` 模式。
3. **双哲学与税务铁律不动**：
   - ISA 核心宽基 60% 四桶政策（上限 65%）与 30% 卫星权重上限不动；
   - 应税 Invest 账户**严禁买入累积型（ACC）离岸 ETF**（英国 ERI 报税红线），仅允许派息型（DIST）核心宽基（`VWRL.L / ISF.L / VERX.L / VEUR.L`），且须遵守「ISA 核心缺口优先于 Invest 宽基部署」原则。
4. **枚举与数据库向后兼容**：
   - 保留现有状态名 `"RISK_ON"`、`"NEUTRAL"`、`"RISK_OFF"`，仅新增 `"RECOVERY"`（绝不重命名旧枚举，避免破坏 16 个源码模块、174+ 单测与线上 `data/advisor.db` 中的 `prev_gate_state`）；
   - SQLite 严格走 `AdvisorDatabase._connect(write=True)` 单写锁，仅做幂等建表/加列；严禁改动出网白名单常量或泄露 `.env` 凭据。
5. **同波次口径一致**：凡调整市场形态、R:R 门槛、止盈或资金路径，必须在同一模块内同步更新 `prompts.py` 与 `semantic_auditor.py`，杜绝模型与 Python 护栏互掐。

### 模块 M5：资本效率与双账户解卡（Invest 派息宽基蓄水池 + 清宽基换股机制 + ISA 边角料解卡）

- **目标**：解决 Invest 长期闲置现金拖累（采纳方案 A：派息宽基 Beta 蓄水池 + 必要时自动生成清宽基换股指令），并解除 ISA 小额历史边角料锁死危机价值通道的问题。
- **涉及文件**：
  - `config.yaml`、`src/config.py`
  - `src/engine/deployment_gate/ledgers.py`、`triggers.py`、`banner.py`
  - `src/engine/portfolio_rules/holding_eval.py`、`risk_override.py`
  - `src/agents/pick_agent.py`、`src/agents/prompts.py`
- **核心设计要点与防坑清单**：
  1. **Invest 派息宽基 Beta 蓄水池（严守英国 ERI 税规）**：
     - **准入四锁**：① `regime in {"RISK_ON", "NEUTRAL"}`（`RISK_OFF / RECOVERY` 不新建）；② ISA 核心宽基已达标（或 ISA 可用现金 `<= 15%`，遵守免税账户优先）；③ Invest 闲置现金占比 `> 50%`；④ 仅限白名单**派息型 LSE 宽基 ETF**（`VWRL.L / ISF.L / VERX.L / VEUR.L`，0% 换汇、0% 印花税、无 ERI 报税麻烦）。
     - **现金防抖缓冲带（Anti-Churn Buffer）**：蓄水池只吸收**超出 `30%` 现金预留带**的溢出资金——即永远为 Invest 保留约 30% 流动现金（~3 笔右侧个股弹药），保证 90% 的常规建仓无需折腾宽基、极度节省英国 CGT 与价差摩擦。
     - **零占用隔离**：Invest 派息宽基占用 **0 个股槽位、0% 热力、零周/月配额**；且在 `holding_eval.py` 中旁路短线个股 ATR `-8%` 止损与 `-8.5%` 移动止盈（仅在 `RISK_OFF` 提示防御评估或减持腾资，绝不触发连损冷静期）。
  2. **合适猎物触发「清宽基换股（ETF-to-Equity Funding）」确定性机制**：
     - 当 `/pick` 或 `/report` 出现通过全部硬护栏（R:R、ATR 地板、槽位/热力）的高确定性右侧个股买单，且 **`Invest 可用流动现金 < 建议建仓金额`**，同时 Invest 持有派息宽基蓄水池时：
     - Python 确定性计算缺口 `need_gbp = ceil((ticket_gbp - free_cash_gbp) * 1.02)`（含 2% 价差/汇率缓冲），结合宽基现价自动生成配对前置指令：`[资金腾挪·零Quota] 先卖出 Invest VWRL.L £X (≈Y股) 释放现金 → 再建仓 SYMBOL £Z`（同时标明是否涉及 GBP→USD 单边 0.15% 换汇，以及 CGT 提示）。
     - 若自由现金已足够覆盖建仓额，**绝不触碰宽基**（零多余换手）。
  3. **ISA 边角料席位解卡**：
     - 保持 `isa_satellite_max_total_pct = 30.0%` 总权重红线一毫米不动；
     - 在统计 `committed_satellite_count`（上限 8 只）时，对 `< min_isa_equity_order_gbp`（£1,200）且**已挂出全额卖出限价单**的历史边角料不计入新增锁定席位（避免 1 只待卖的 £300 碎仓锁死危机价值通道），并在早报继续温和提示剩余边角料归核。

### 模块 M6：进攻可观测性与离线 A/B 验证闭环（防过拟合安全阀）

- **目标**：建立客观度量闭环，避免凭感觉调参；通过影子对照组（Shadow Counterfactual）量化“风控挡雷 vs 护栏误杀”。
- **涉及文件**：
  - `src/engine/screener/audit.py`
  - `src/storage/db/schema.py`、`src/storage/db/recommendations_repo.py`
  - `src/bot/scheduler/settlement_mixin.py`
  - `src/data_providers/analytics/performance.py`
- **核心设计要点与防坑清单**：
